## 🚀 How to Run Locally
1. **Download the project**  
   - Click the green `Code` button and choose **Download ZIP**, or  
   - Clone with Git:  
     ```bash
     git clone https://github.com/suvesh95/codsoft-main.git
     ```
2. **Extract the files**
3. **Open** any `.html` file in your browser to view the project.
